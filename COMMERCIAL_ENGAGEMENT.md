# Commercial Engagements

This repository shows TSquared's evidence discipline without publishing the production pipeline.

## Suggested first milestones

| Milestone | Typical fixed scope | Indicative price |
|---|---|---:|
| rPPG data and protocol audit | Reference integrity, synchronization, leakage, metrics, and risk register | $750–$1,000 |
| Baseline reproduction and benchmark | One dataset, agreed baseline, environment lock, coverage/tail report | $1,500–$2,500 |
| Robustness and temporal-estimation sprint | Agreed preprocessing/SQI/temporal work, tests, benchmark, failure analysis | $3,000–$5,000 |

Every engagement starts by defining the intended decision, data rights, reference device or
waveform, allowed claims, operating conditions, acceptance criteria, and exclusions. No numerical
result in this repository is promised for a client's population, camera, protocol, or intended
use.
