# Public Disclosure Boundary

## Public in this repository

- Aggregate benchmark counts and results shown in the accuracy statement.
- Source citations, scope boundaries, failed gates, and material limitations.
- Commercial scope examples.

## Private TSquared intellectual property

- Production preprocessing and tracking source code.
- Metric, reporting, validation, and disclosure-audit source code and tests.
- Exact quality, temporal, and reacquisition policies and parameters.
- Model adapters, checkpoints, state handling, and evaluation orchestration.
- Dataset download, synchronization, selection, and subject-level analysis tools.
- Raw or derived subject-level physiological data.
- Confidential client, product, and business information.
- Client materials and results.

The public material is intentionally insufficient to reproduce either the production pipeline or
the retained validation package. Access to additional implementation or evidence requires a
separately scoped commercial engagement and any necessary confidentiality/data-use agreement.
